# Command and Scripting Interpreter: Windows Command Shell

**Technique ID:** T1059.003  
**Tactic:** Execution  
**Parent Technique:** T1059 - Command and Scripting Interpreter  

## Overview

Adversaries may abuse the Windows command shell (`cmd.exe`) to execute commands, batch scripts (`.bat`, `.cmd`), or execute commands indirectly via environment variables or living-off-the-land binaries (LOLBins).

## Execution Patterns

- **Batch Execution:** Execution of `.bat` or `.cmd` files from temporary directories like `C:\Users\Public\`, `C:\Windows\Temp\`, or `C:\Users\<user>\AppData\Local\Temp\`.
- **Command Chaining:** Using `&`, `&&`, or `||` to execute multiple commands in a single command line (e.g. `whoami & net user & ipconfig /all`).
- **Indirect Execution via `cmd.exe /c`:** Command shell invoked non-interactively to run discovery or persistence commands.

## Detection Indicators

1. Process creation of `cmd.exe` with arguments containing `whoami`, `net user`, `net localgroup administrators`, `systeminfo`, or `tasklist`.
2. `cmd.exe` launched by suspicious processes like `wmiprvse.exe`, `rundll32.exe`, or `mshta.exe`.
3. Pipe redirection (`>`) writing output to temporary text files in public directories.

## Mitigation & Controls

- Audit command line executions via Event ID 4688 with command-line auditing enabled.
- Restrict interactive `cmd.exe` usage for non-administrative user roles where feasible.
